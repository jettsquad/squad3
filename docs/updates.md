# 软件更新

设置页提供两条路径，均使用同一个更新器的版本比较、缓存校验和退出安装流程，保留用户数据。

- 检查更新：读取 GitHub Release 元数据，发现更新后自动获取安装包；已有相同 SHA-512 的有效缓存时直接复用。
- 从本地安装更新：选择本机的 Squad-Setup-版本.exe，同目录须有匹配的 latest.yml。检查版本和 SHA-512，复制到私有更新缓存，再点击「重启并安装更新」。安装包不会上传，也不会从互联网重新下载。

本地入口只在已安装的 Windows 版中运行。它只在 127.0.0.1 临时提供一小份由已验证字段生成的版本元数据，安装包从更新缓存直接使用；不提供 exe 下载接口，15 分钟后关闭临时入口。应用退出后端口也会释放。

哈希校验确认文件与所选发布元数据一致，不代表第三方包可信。应选择本人构建或项目发布的安装包。本地入口不接受降级、同版本重复安装、文件名/版本不匹配或校验失败的包。

发布时上传 exe、exe.blockmap、latest.yml；预发布另附相同元数据的 dev.yml，使用与 package.json 一致的 v 标签。安装器应对应发布标签的源码提交；不要用不同构建覆盖已经发布的同名附件。Windows-only 发布只声明 Windows 已验证，不附带旧版 macOS 包。
